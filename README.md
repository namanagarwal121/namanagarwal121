#### Featured projects

**Microsoft Fabric**
- [employee-hub-fabric-app](https://github.com/namanagarwal121/employee-hub-fabric-app): An employee management app on Fabric Apps (React, Vite), with server-enforced roles, an audit log and CSV import/export.
- [employee-hub-data-platform](https://github.com/namanagarwal121/employee-hub-data-platform): Incremental + CDC pipeline from the app's Fabric SQL database to an SCD2 star schema and a Power BI semantic model.

**Databricks and streaming**
- [restaurant-lakehouse-pipeline](https://github.com/namanagarwal121/restaurant-lakehouse-pipeline): A restaurant lakehouse built from three declarative pipelines: config-driven bronze with Event Hub streaming, CDC silver, and SCD2 gold.
- [databricks-cdc-star-schema-engine](https://github.com/namanagarwal121/databricks-cdc-star-schema-engine): A config-driven flight-booking star schema using Auto Loader, AUTO CDC and Delta MERGE.
- [wikimedia-eventhub-databricks-pipeline](https://github.com/namanagarwal121/wikimedia-eventhub-databricks-pipeline): A live Wikimedia feed streamed through Event Hubs into bronze, silver and SCD2 gold tables.
- [uber_AzureEventHub_project](https://github.com/namanagarwal121/uber_AzureEventHub_project): Uber rides, batch plus streaming, modelled into SCD1 and SCD2 dimensions and a fact table.
- [retail_q_databrciks_project](https://github.com/namanagarwal121/retail_q_databrciks_project): A retail analytics platform with declarative pipelines, a gold star schema and a metric-view semantic layer.
- [crypto-streaming-project](https://github.com/namanagarwal121/crypto-streaming-project): BTC/ETH prices through Kafka and Spark Structured Streaming into Delta bronze and silver.

**Azure Data Factory**
- [azure_DataFactory_ci_cd](https://github.com/namanagarwal121/azure_DataFactory_ci_cd): Data Factory pipelines for incremental SQL, REST API pagination and Delta upserts, with Git-based CI/CD.
- [azureproject](https://github.com/namanagarwal121/azureproject): Metadata-driven incremental ingestion from Azure SQL to ADLS, with Logic App alerts.
- [AdventureWorks_AzureProject](https://github.com/namanagarwal121/AdventureWorks_AzureProject): Data Factory, Databricks and Synapse serverless across the bronze, silver and gold layers.
- [nyc_taxi_azure_project](https://github.com/namanagarwal121/nyc_taxi_azure_project): NYC green taxi data for 2023, from Data Factory ingestion to Databricks silver and gold Delta tables.
- [ParisOlympics_Azure_project](https://github.com/namanagarwal121/ParisOlympics_Azure_project): Paris Olympics data through Data Factory into Databricks silver Delta tables.
- [Azure_DataFactory_Project_I](https://github.com/namanagarwal121/Azure_DataFactory_Project_I): Scheduled file routing and a mapping data flow that aggregates payment data.

**Analytics and BI**
